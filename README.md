# GuessMaster-25

An interactive Number Guessing Game built using **HTML, CSS, and JavaScript**.

The player has to guess a hidden number between **1 and 25** by clicking on the number boxes.  
After every guess, the game provides a hint whether the selected number is **greater or lower** than the hidden number.

The game also keeps track of:
- Current Score
- Best Score (Highest score achieved before page refresh)

Once the correct number is guessed, the game automatically restarts so the player can continue playing again.

---

## Features

- Interactive number selection
- Live hints after every guess
- Score decreases on wrong guesses
- Best score tracking
- Automatic game restart after winning
- Simple and responsive UI
- Built with pure HTML, CSS & JavaScript

---

## Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)

---

## How to Play

1. Start the game — a random number between **1 and 25** is chosen secretly.  
2. Click on any number box to make your guess.  
3. After each guess:
   - If your guess is too high, you’ll see a hint: *Lower*.  
   - If your guess is too low, you’ll see a hint: *Higher*.  
4. Each wrong guess reduces your score.  
5. When you guess correctly:
   - The correct number box turns green.  
   - The game automatically restarts with a new hidden number.  
6. Your **Best Score** is saved until you refresh or close the page.
